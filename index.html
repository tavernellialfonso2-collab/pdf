SUITE PDF

Procesamiento Local

Filtrar Cuadruplicados

Sube un PDF. Conservará todas las páginas excepto aquellas que contengan la palabra "CUADRUPLICADO".

Unir Archivos PDF

Selecciona múltiples archivos PDF para combinarlos en un solo documento final.

Extraer Rango de Páginas

Extrae un bloque de páginas específico de un documento grande.

Estampar Documento

Aplica un texto (ej. "APROBADO", "PROCESADO") sobre todas las páginas.

Rotar PDF

Gira todas las páginas 90 grados a la derecha.

Editor Visual (Parche y Corrección)

Sube un PDF, selecciona la página, haz clic sobre el error para ubicarlo y escribe el texto nuevo con la misma tipografía.

Haz clic sobre la previsualización para capturar las coordenadas aproximadas del texto a corregir.
